## 🙋‍♂️ 소개

서울에서 활동 중인 5년 차 백엔드 개발자입니다.
커머스 도메인에서 대용량 트래픽을 다루는 API 서버를 설계하고 운영해 왔습니다.
문제를 코드로 푸는 것보다, 코드를 줄여서 푸는 쪽을 더 좋아합니다.

- 🏢 현재 (주)클라우드베리에서 결제 플랫폼 팀 소속
- 🌱 요즘은 **Rust**와 **eBPF 기반 관측성**을 파고 있습니다
- 💬 아키텍처 설계, 성능 튜닝, 코드 리뷰 문화에 대한 이야기를 좋아합니다
- ☕ 커피 3잔 이하로 하루를 버티는 것이 올해 목표입니다

## 📌 주요 프로젝트

### 결제 게이트웨이 리뉴얼 (2024)
레거시 모놀리식 결제 모듈을 이벤트 기반 마이크로서비스로 전환했습니다.
- 평균 응답 시간 **820ms → 140ms** 개선
- Kafka 기반 비동기 정산 파이프라인 도입
- 결제 실패율 0.7% → 0.08%

### 실시간 재고 동기화 시스템 (2023)
전국 120개 오프라인 매장과 온라인몰의 재고를 실시간 동기화했습니다.
- Redis Streams + 분산 락으로 중복 차감 문제 해결
- 일 평균 400만 건 이벤트 처리

### 사내 배포 자동화 도구 (2022)
수동 배포 절차를 GitHub Actions 기반 파이프라인으로 통합했습니다.
- 배포 소요 시간 40분 → 6분
- 롤백 원클릭화
